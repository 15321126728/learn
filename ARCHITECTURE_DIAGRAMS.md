## 3. 解析流程图

### 3.1 总体解析流程

```
┌─────────────┐
│  开始解析    │
└──────┬──────┘
       │
       ▼
┌──────────────────────┐
│ parseExpr()          │  ← 入口方法
│ (解析表达式)          │
└──────┬───────────────┘
       │
       ▼
┌──────────────────────┐
│ parseTerm()          │  ← 解析第一项
│ (解析项)              │
└──────┬───────────────┘
       │
       ▼
┌──────────────────────┐
│ parseFactor()        │  ← 解析因子
│ (解析因子)            │
└──────┬───────────────┘
       │
       ▼
┌──────────────────────┐
│ 返回 Poly 对象       │
└──────┬───────────────┘
       │
       ▼
┌──────────────────────┐
│ 检查是否有 +/- ?     │
└──────┬───────────────┘
       │
       ├─ 是 ──> 解析下一项 ──> 执行加/减 ──┐
       │                                    │
       └─ 否 ──> 返回结果 <─────────────────┘
```

### 3.2 parseExpr 详细流程

```
parseExpr() {
    
    result = parseTerm()  ─────────┐
                                   │
    ┌──────────────────────────────┘
    │
    ▼
    ┌─────────────────────┐
    │ while (peek() in    │
    │  {'+', '-'})        │
    └─────┬───────────────┘
          │
          ▼
    ┌─────────────────────┐
    │ op = consume()      │  读取运算符
    └─────┬───────────────┘
          │
          ▼
    ┌─────────────────────┐
    │ right = parseTerm() │  解析右侧项
    └─────┬───────────────┘
          │
          ▼
    ┌─────────────────────┐
    │ if (op == '+')      │
    │   result += right   │
    │ else                │
    │   result -= right   │
    └─────┬───────────────┘
          │
          └──> 继续循环或退出
          
    return result
}
```

### 3.3 parseTerm 详细流程

```
parseTerm() {
    
    ┌────────────────────┐
    │ 检查前导符号        │
    │ sign = 1 或 -1     │
    └────┬───────────────┘
         │
         ▼
    ┌────────────────────┐
    │ result =           │
    │ parseFactor()      │  解析第一个因子
    └────┬───────────────┘
         │
         ▼
    ┌────────────────────┐
    │ if (sign < 0)      │
    │   result = -result │  应用符号
    └────┬───────────────┘
         │
         ▼
    ┌────────────────────┐
    │ while (peek()=='*')│  处理乘法
    └────┬───────────────┘
         │
         ▼
    ┌────────────────────┐
    │ consume('*')       │
    └────┬───────────────┘
         │
         ▼
    ┌────────────────────┐
    │ right =            │
    │ parseFactor()      │
    └────┬───────────────┘
         │
         ▼
    ┌────────────────────┐
    │ result *= right    │
    └────┬───────────────┘
         │
         └──> 继续循环或退出
         
    return result
}
```

### 3.4 parseFactor 详细流程

```
parseFactor() {
    
    ┌─────────────────────┐
    │ 检查第一个字符       │
    └────┬────────────────┘
         │
         │
    ┌────┴─────┬─────────┬─────────┐
    │          │         │         │
    '('        'x'      数字     其他
    │          │         │         │
    ▼          ▼         ▼         ▼
┌────────┐ ┌──────┐ ┌────────┐ ┌──────┐
│表达式  │ │变量  │ │常数    │ │错误  │
│因子    │ │因子  │ │因子    │ │      │
└────────┘ └──────┘ └────────┘ └──────┘

【表达式因子】          【变量因子】        【常数因子】
consume('(')            consume('x')        val = parseBigInteger()
    ↓                       ↓                   ↓
res = parseExpr()       exp = 1             return Poly(val, 0)
    ↓                       ↓
consume(')')            if (peek() == '^')
    ↓                       ↓
if (peek() == '^')      consume('^')
    ↓                       ↓
consume('^')            exp = parseSimpleInt()
    ↓                       ↓
exp = parseSimpleInt()  return Poly(1, exp)
    ↓
return res.pow(exp)
}
```

## 5. 算法流程图

### 5.1 多项式加法

```
add(Poly other) {
    
    ┌────────────────────┐
    │ 创建新多项式 res    │
    └────┬───────────────┘
         │
         ▼
    ┌────────────────────┐
    │ 复制 this.terms    │
    │ 到 res.terms       │
    └────┬───────────────┘
         │
         ▼
    ┌────────────────────┐
    │ 遍历 other.terms   │
    └────┬───────────────┘
         │
         ▼
    ┌────────────────────┐
    │ 对每个 (exp, coeff)│
    └────┬───────────────┘
         │
         ▼
    ┌────────────────────────────┐
    │ if res.terms 包含 exp      │
    │   res.terms[exp] += coeff  │
    │ else                       │
    │   res.terms[exp] = coeff   │
    └────┬───────────────────────┘
         │
         ▼
    ┌────────────────────┐
    │ res.cleanup()      │  清理零项
    └────┬───────────────┘
         │
         ▼
    return res
}

示例:
(3x^2 + 2x) + (x^2 - x + 1)

步骤1: res = {2: 3, 1: 2}        (复制第一个)
步骤2: res[2] += 1 → {2: 4, 1: 2}
步骤3: res[1] += -1 → {2: 4, 1: 1}
步骤4: res[0] = 1 → {2: 4, 1: 1, 0: 1}
结果: 4x^2 + x + 1
```

### 5.2 多项式乘法

```
multiply(Poly other) {
    
    ┌────────────────────┐
    │ 创建新多项式 res    │
    └────┬───────────────┘
         │
         ▼
    ┌────────────────────────────┐
    │ for each (exp1, coeff1)    │
    │   in this.terms            │
    └────┬───────────────────────┘
         │
         ▼
    ┌────────────────────────────┐
    │   for each (exp2, coeff2)  │
    │     in other.terms         │
    └────┬───────────────────────┘
         │
         ▼
    ┌────────────────────────────┐
    │     newExp = exp1 + exp2   │
    │     newCoeff = coeff1 *    │
    │                coeff2      │
    └────┬───────────────────────┘
         │
         ▼
    ┌────────────────────────────┐
    │     res.terms[newExp]      │
    │       += newCoeff          │
    └────┬───────────────────────┘
         │
         └──> 继续内外循环
         
    ┌────────────────────┐
    │ res.cleanup()      │
    └────┬───────────────┘
         │
         ▼
    return res
}

示例:
(2x + 1) × (x + 3)

步骤1: 2x × x = 2x^2      → res[2] = 2
步骤2: 2x × 3 = 6x        → res[1] = 6
步骤3: 1 × x = x          → res[1] += 1 = 7
步骤4: 1 × 3 = 3          → res[0] = 3

结果: {2: 2, 1: 7, 0: 3} → 2x^2 + 7x + 3
```

### 5.3 符号简化

```
simplifySign(String s) {
    
    ┌────────────────────┐
    │ changed = true     │
    └────┬───────────────┘
         │
         ▼
    ┌────────────────────┐
    │ while (changed)    │
    └────┬───────────────┘
         │
         ▼
    ┌────────────────────┐
    │ original = s       │
    └────┬───────────────┘
         │
         ▼
    ┌────────────────────┐
    │ s = replace("++"," │
    │       "+"          │
    │   = replace("--",  │
    │       "+")         │
    │   = replace("+-",  │
    │       "-")         │
    │   = replace("-+",  │
    │       "-")         │
    └────┬───────────────┘
         │
         ▼
    ┌────────────────────┐
    │ changed =          │
    │  !s.equals(        │
    │    original)       │
    └────┬───────────────┘
         │
         └──> 循环直到不变
         
    return s
}

示例:
"---1"
 → "--1"   (第1轮)
 → "+1"    (第2轮)
 → "+1"    (不变,退出)
```
